## 📋 Overview & Core Idea

**Horus-Safe-Script** is a hospital clinical decision-support system built in Java. In fast-paced medical environments, prescribing standard treatments without cross-referencing a patient's chronic conditions (such as Hypertension, Diabetes, Heart Disease, or Asthma) can lead to severe adverse reactions.

This system acts as a safety shield:
1. **Patient Intake:** Collects the patient's current symptoms alongside their chronic medical history.
2. **Smart Cross-Referencing:** Scans the hospital's pharmaceutical database (`drugs_db.csv`), filters medications that treat the active illness, and **automatically eliminates** any drug contraindicated with the patient's chronic conditions.
3. **Billing & Logging:** Recommends only verified, safe alternatives with transparent pricing, calculates the prescription bill, and archives the visit in `patients_log.csv`.
4. **Administrative Control:** Provides a password-protected Admin Dashboard to manage drug pricing, expand the database, and audit patient prescription logs.

## ✨ Key Features

| Module | Capabilities |
| :--- | :--- |
| **🩺 Clinical Engine** | Multi-condition contraindication filtering (excludes unsafe drugs automatically with clear warnings). |
| **👤 Patient Profiling** | Recognizes returning patients from `patients_log.csv` and recalls their chronic history automatically. |
| **💰 Automated Billing** | Real-time calculation of total prescription costs based on dynamic CSV pricing. |
| **🔐 Admin Dashboard** | Password-protected portal to add new medications, update prices, and review hospital visit logs. |
| **🧱 GUI-Ready Architecture** | Strict separation between business logic (`MedicalLogic`, `AdminLogic`) and the UI (`Main`), enabling seamless migration to JavaFX/Swing without rewriting core algorithms. |

## 🏗️ Project Architecture

Designed using a **Modular Layered Structure** tailored for clean code and future GUI integration:

```text
Horus-Safe-Script/
├── src/
│   ├── Main.java               # Presentation Layer (CLI Menus & User I/O)
│   ├── HospitalData.java       # Data Access Layer (CSV Parsing & Memory Storage)
│   ├── MedicalLogic.java       # Business Logic (Drug Filtering & Safety Engine)
│   └── AdminLogic.java         # Management Logic (Auth, Billing & Log Auditing)
├── bin/                        # Compiled .class files (Auto-generated by VS Code)
├── lib/                        # External dependencies (Reserved for JavaFX/UI libraries)
├── drugs_db.csv                # Pharmaceutical database (Name, Disease, Contraindications, Price)
├── patients_log.csv            # Persistent patient records and issued prescriptions
└── README.md                   # Project documentation
🧠 Core Filtering Algorithm
Code snippet
flowchart TD
    A[Start Patient Check-up] --> B[Input: Active Disease + Chronic Conditions]
    B --> C{Loop Through drugs_db.csv}
    C --> D{Matches Active Disease?}
    D -- No --> C
    D -- Yes --> E{Conflicts with Chronic Conditions?}
    E -- Yes --> F[Exclude Drug & Log Safety Warning]
    E -- No --> G[Add to Safe Recommendations List]
    F --> C
    G --> C
    C -- Loop Done --> H{Safe List Empty?}
    H -- Yes --> I[Alert: Refer to Specialist Immediately]
    H -- No --> J[Display Safe Drugs & Prices -> Generate Bill & Save Log]

🚀 Getting Started (VS Code)
Prerequisites
Java Development Kit (JDK): Version 17 or higher.

IDE: Visual Studio Code with the Extension Pack for Java installed.

Running the Project
Clone or download the Horus-Safe-Script repository.

Ensure drugs_db.csv is placed in the root directory of the project (alongside src/).

Open src/Main.java in VS Code.

Click Run above the main method (or press F5).
